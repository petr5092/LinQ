# LinQ Safety Guard: инструкция запуска

Актуальная инструкция CV, проверенный статус, команды CPU/TPU и чек-лист сдачи находятся в [CV_HANDOFF.md](CV_HANDOFF.md).

Старые команды с `requirements-linq-safety.txt`, `app/detector.py`, `--classes` и единым демо-сервисом относились к другой структуре проекта и удалены, чтобы не вести к несуществующим файлам и параметрам.
