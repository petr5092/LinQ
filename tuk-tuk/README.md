# Тук-Тук

Светлый интерактивный прототип сервиса промышленной безопасности. React 19, TypeScript, Vite. Основан на локальной HR Vision Design System и лейауте Figma HR DS, предоставленных для задачи. Исходная дизайн-система сохранена в соседней папке без изменений.

## Запуск

```sh
npm install
npm run dev -- --host 0.0.0.0 --port 5173
```

Проверка и сборка: `npm run build`. Статический результат находится в `dist/`.

## Сценарии

- Обзор с видеомониторингом, схемой объекта и показателями смены.
- Камеры: выбор площадки, фильтры по цеху и зоне, поиск, сетка/список, скрытие детекций, пример потери сигнала.
- Постоянная лента справа: непрочитанные, критические, отметка всех как прочитанных, звуковые демооповещения.
- Журнал: фильтры по зоне, важности, статусу, времени; поиск по сотруднику, событию, камере или ID; экспорт CSV.
- Карточка нарушения: кадр, причина, рекомендуемая реакция, данные сотрудника из СКУД при наличии, рация, телефон с добавочным.
- Смена статуса: новое → в работе → устранено; ложное срабатывание. Статусы исходных событий сохраняются в localStorage браузера.
- Отказ на проходной: нет респиратора при действующем допуске; истёкший допуск с формулировкой «попытка несанкционированного прохода».
- Три площадки, семь цехов и пятнадцать зон; в каждой зоне минимум четыре камеры (всего 61). Сценарии адаптированы из PDF кейса LinQ.
- Нарушения среды: ящик в проходе, лужа у станка. Уведомления доступны без идентификации сотрудника.
- Переключение аккаунтов в левом нижнем углу: диспетчер, мастер смены, руководитель. Смена площадки в шапке сайдбара переключает камеры, события и ленту.
- Аналитика, настройки и восстановление демоданных.

Видео, сотрудники, контакты, СКУД, показатели и LinQ — демонстрационные. Бэкенд и реальная детекция не реализованы. Изображения камер — сгенерированные иллюстрации, воспроизведение имитирует просмотр статичного фрагмента. Кнопки не отправляют сообщения и не звонят.

## Дизайн и ассеты

Figma: https://www.figma.com/design/BhE5DjEG56PsuPqjShao4X/HR-DS?node-id=36585-35804

Использованы локальные компоненты Button, Dialog, Switch, TooltipProvider, шрифт Roboto Flex, токены и градиент кнопки HR DS. Интерфейс принудительно использует светлую тему.

Изображения сгенерированы встроенным ImageGen и сохранены в `public/images/`: `workshop.png`, `warehouse.png`, `gate.png`, `perimeter.png`. Промпты описывают соответственно общий вид металлообрабатывающего цеха с рабочими, складской проход с оставленным ящиком, проходную с турникетами и сотрудником, северный забор предприятия с человеком. Для всех заданы приподнятая точка камеры, реалистичная фотография, формат 16:9, приглушённая палитра и отсутствие текста, логотипов и интерфейсных рамок. Подписи и рамки добавляет интерфейс.
