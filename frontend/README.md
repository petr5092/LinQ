# LinQ Safety Guard — Веб-интерфейс диспетчера (LinQsec)

Интерактивный операторский веб-интерфейс сервиса промышленной безопасности и контроля охраны труда (ОТ и ТБ).
Построен на **React 19, TypeScript, Vite, Tailwind CSS** и дизайн-системе **HR Vision Design System**.

---

## 🚀 Возможности и интеграция

- **Двусторонняя интеграция с бэкендом (FastAPI)**:
  - Автоматическая синхронизация инцидентов через REST API (`/api/v1/incidents`).
  - Мгновенные push-уведомления через **WebSocket** (`/ws/events`).
  - Смена статусов инцидентов (`PATCH /api/v1/incidents/{id}/status`) с немедленным отражением в БД.
  - Синхронизация списка камер (`/api/v1/cameras`) и площадок (`/api/v1/sites`).
  - **Graceful Fallback**: при отсутствии соединения с бэкендом интерфейс автоматически работает в демо-режиме на локальных моках и сохраняет статусы в `localStorage`.
- **Сценарии мониторинга**:
  - Обзор с видеомониторингом, картографией объекта и ключевыми показателями смены.
  - Камеры: выбор площадки, фильтры по цеху и зоне, поиск, сетка/список, управление оверлеем детекций (боксами), индикация статуса онлайн.
  - Лента оповещений в реальном времени: непрочитанные, критические тревоги, звуковые оповещения.
  - Журнал инцидентов: фильтрация по критичности, статусу, времени, поиск по сотруднику, экспорт в CSV.
  - Карточка нарушения: снапшот нарушения, СКУД-данные сотрудника, рекомендуемое действие, рация и телефон дежурного мастера.

## 🛠️ Запуск в режиме разработки

Для запуска фронтенда с автоматическим проксированием запросов к бэкенду (`http://127.0.0.1:8000`):

```bash
cd frontend
npm install
npm run dev
```

Интерфейс будет доступен по адресу: `http://localhost:3000` (или `http://localhost:5173`).

---

## 📦 Сборка для продакшена

Для сборки оптимизированного бандла:

```bash
npm run build
```

Собранные статические файлы сохраняются в `frontend/dist/`.
Бэкенд FastAPI автоматически монтирует собранный бандл по адресу `http://localhost:8000/ui/`.
