# LenQsec — Операторский веб-интерфейс диспетчера и службы охраны труда

Интерактивный операторский веб-интерфейс комплексной системы промышленной безопасности, видеоаналитики и охраны труда (ОТ и ТБ) **LenQsec**.

Интерфейс построен на современном стеке: **React 19, TypeScript, Vite, Tailwind CSS** и дизайн-системе **HR Vision Design System**.

---

## 🚀 Возможности операторского интерфейса

### 1. Видеомониторинг и телеметрия
- **Многокамерная сетка и детальный просмотр**:
  - Поддержка форматов потоков: RTSP, WebRTC (go2rtc), MJPEG, снимки высокого разрешения.
  - Динамический оверлей: отображение детекций нейросети (bounding box'ы людей и техники) и цветных полигонов опасных зон.
  - Индикация статусов камер в реальном времени (онлайн / офлайн / сбой потока).
- **Интеграция радиометрических тепловизоров**:
  - Отображение термограмм ИК-спектра высокого контраста (палитра Inferno / Jet).
  - Прямое получение радиометрических JPEG-кадров по эндпоинту `/api/v1/thermal/cameras/{camera_id}/heatmap.jpg`.
  - Отображение текущих температур в контрольных зонах оборудования и индикация риска перегрева.

### 2. Интерактивный редактор полигонов зон
- Инструмент рисования произвольных многоугольников зон прямо поверх живого видеокадра камеры.
- Настройка типов зон: «Опасная зона», «Зона обязательного ношения СИЗ», «Зона движения техники».
- Привязка правил безопасности и задание порогов срабатывания.

### 3. Лента оповещений и оперативный контроль
- Мгновенные push-уведомления диспетчера через **WebSocket** (`/ws/events`).
- Звуковая сигнализация критических нарушений (с возможностью отключения).
- Счетчик непрочитанных и критических тревог в реальном времени.

### 4. Журнал инцидентов и доказательная база
- Полнотекстовый поиск и многофакторная фильтрация:
  - По уровню критичности (`critical`, `warning`, `info`);
  - По типу нарушения (`danger_zone`, `no_helmet`, `no_vest`, `fall_detection`, `proximity`, `environment`);
  - По статусу расследования (`new`, `investigating`, `resolved`, `false_positive`);
  - По камере, цеху и временному интервалу смены.
- Экспорт сводного журнала инцидентов в формат **CSV**.

### 5. Детальная карточка нарушения
- Полноразмерный стоп-кадр или термограмма момента фиксации с графическим выделением нарушения.
- СКУД-карточка сотрудника (ФИО, табельный номер, должность, квалификация, допуски по ТБ).
- Рекомендуемый алгоритм действий оператора диспетчерской службы.
- Быстрый вызов дежурного мастера цеха по рации или телефону.
- Интерактивная смена статуса расследования с синхронизацией в БД (`PATCH /api/v1/incidents/{id}/status`).

### 6. Аналитический дашборд и отчетность
- Графика ключевых показателей за смену: динамика нарушений, процент ношения СИЗ, среднее время реагирования на тревоги.
- Скачивание типовой памятки по промышленной безопасности для сотрудников (`lenqsec-pamyatka-po-bezopasnosti.txt`).
- Экспорт и импорт пользовательских настроек площадок (`lenqsec-settings-{siteId}.json`).

### 7. Ролевая модель и надежность
- Переключение ролей: «Инженер по охране труда», «Оператор видеонаблюдения», «Начальник смены», «Администратор».
- **Graceful Fallback**: при временной недоступности бэкенда интерфейс автоматически переходит в автономный демо-режим с локальной эмуляцией и сохранением изменений в `localStorage`.

## 🛠️ Запуск в режиме разработки

Для запуска фронтенда с автоматическим проксированием запросов к бэкенду (`http://127.0.0.1:8000`):

```bash
cd frontend
npm install
npm run dev
```

Интерфейс будет доступен по адресу: `http://localhost:3000` (или `http://localhost:5173`).

---

## 📦 Сборка для продакшена

Для сборки оптимизированного бандла:

```bash
cd frontend
npm run build
```

Собранные статические файлы сохраняются в `frontend/dist/`.  
Бэкенд FastAPI автоматически раздает собранный статический бандл по корневому адресу `http://localhost:8000/`.
