# OSF radiometric sample

`Beef_LR_38_20_30.csv` is one low-resolution original temperature matrix from the OSF dataset **Capturing Material Thermal Responses under RF-Induced Hyperthermia: An Experimental Imaging Database**.

- Source: https://doi.org/10.17605/OSF.IO/5JRTA
- Original OSF file: https://osf.io/download/68efdbf4090b7314c6f97cde/
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- File size: 28,450 bytes
- SHA-256: `97b877f43108607d3b050d5a6a53cc1b4a75f375a2434e0fc46fc790cd362944`
- Matrix: 80 rows × 60 columns; Celsius values
- Measured range in this sample: 18.85–22.37 °C

The matrix is included for software integration checks. It is a single laboratory capture, not a time sequence and not a production-motor recording. Replaying it several times only exercises API delivery and frame-count debounce; it does not establish a real thermal trend.

Dataset article: Ortiz-Santana, P. et al. (2026), “Capturing Material Thermal Responses under RF-Induced Hyperthermia: An Experimental Imaging Database,” F1000Research 14:1379, https://doi.org/10.12688/f1000research.171954.2. Dataset DOI: 10.17605/OSF.IO/5JRTA.
