> **Аппаратная платформа**: Российский ИИ-ускоритель **LinQ TPU (H1M)**  
> **Дата актуализации**: 25 октября 2026 года.  
> **Текущий статус тестов**: **221 passed, 0 failed** (pytest в изолированном `.venv`).

## 1. Текущий статус готовности системы

* **Ядро компьютерного зрения и трекинг**:
  * Полностью реализован и протестирован конвейер детекции на базе моделей YOLOv8/YOLO11 со статическим входом `[1, 3, 640, 640]`.
  * Интегрирован трекер **ByteTrack** во времени: устойчивое сохранение `Track ID`, фильтрация кратковременных перекрытий, расчет векторов скоростей и состояний объектов.
* **Движок правил безопасности (Safety Rules Engine)**:
  * Проверка произвольных полигонов опасных зон через `Shapely` (`Point-in-Polygon`);
  * Контроль ношения СИЗ (каски, жилеты);
  * Детекция падений и неподвижности ($w/h > 1.2$, нулевая скорость более 2 с);
  * Предупреждение опасного сближения персонала с техникой (погрузчики, кары);
  * Единый модульный реестр `RULE_REGISTRY` в `engine/rules/registry.py`.
* **Радиометрический тепловизионный контур**:
  * Приём сырых температурных матриц в °C (`POST /api/v1/thermal/cameras/{id}/frame`);
  * Зональный контроль и автоматическая фиксация инцидентов `environment` при превышении температуры;
  * Прямая отдача термограмм в веб-интерфейс (`/api/v1/thermal/cameras/{id}/heatmap.jpg`) и интеграция в `CameraHub`;
  * Верификация на эталонном датасете OSF (`data/thermal/osf_sample/`).
* **Аппаратная интеграция с LinQ TPU**:
  * Реализован адаптер `linq_adapter.py` по спецификации SDK 2026.9.45 с нативным методом `sync()` и fallback `run()`;
  * Подготовлен мост `tools/stand_tpu_bridge.py` и автономный пакет развертывания `linq_deploy_bundle/`;
  * Единый HAL (`BaseInferenceEngine`) с прозрачным переключением `LINQ_TPU` / `ONNX_CPU` / `MOCK`.
* **Дедупликация и защита от спама (Anti-Spam)**:
  * Temporal Debounce ($N$ кадров устойчивого подтверждения);
  * Cooldown по `Track ID` (одно уведомление на длящийся инцидент);
  * 5-минутное окно слияния повторных нарушений;
  * Outbox pattern с дисковой очередью при потере сетевого соединения.
* **Каналы оповещений и Web UI**:
  * Telegram-бот с интерактивными кнопками управления статусами инцидентов;
  * WebSocket-рассылка реального времени (`/ws/events`);
  * Операторский веб-интерфейс на React 19 + TypeScript (видеомониторинг, редактор полигонов, журнал, аналитика смен).

## 2. Сводка исправлений и ключевых улучшений

| Проблема / Ограничение | Реализованное решение в LenQsec |
|---|---|
| Отсутствующая модель приводила к скрытому падению | Четкая диагностика в HAL: понятная ошибка при отсутствии файла; явное включение MOCK для тестов |
| Некорректный маппинг классов на детекторах | Чтение метаданных `names` напрямую из ONNX/манифеста; валидация схемы классов |
| Искажение координат при нечетном letterbox-паддинге | Математически точный дескриптор обратного преобразования координат с учетом паддинга и масштаба |
| Ложные срабатывания от единичных выбросов детекции | Temporal Debounce (15 кадров подряд) и ассоциация во времени через ByteTrack |
| Заспамливание диспетчера при долгом нарушении | Cooldown по объекту и 5-минутное объединение повторных событий в существующую карточку инцидента |
| Потеря инцидентов при сбоях сети | Отказоустойчивый `IncidentClient` с дисковой очередью (Outbox pattern) |
| Отсутствие поддержки тепловизоров | Радиометрический контур: приём матриц °C, палитра Inferno, пороги в YAML, стриминг термограмм |
| Задержки передачи сырых тензоров через VPN | Архитектура Fast Bridge: передача JPEG на стенд, локальный препроцессинг и инференс на TPU |

## 3. Чек-лист проверки и команды для запуска

### 1. Запуск модульных тестов
```powershell
.\.venv\Scripts\python.exe -m pytest -v
```
*Ожидаемый результат: 221 passed.*

### 2. Запуск бэкенда LenQsec
```powershell
.\.venv\Scripts\python.exe run.py
```
*Эндпоинты:*
* Веб-панель: `http://localhost:8000`
* Документация API Swagger: `http://localhost:8000/docs`

### 3. Запуск CV-воркера на тестовом видео (ONNX CPU)
```powershell
.\.venv\Scripts\python.exe run_worker.py --config configs/cv_person.yaml --backend onnx_cpu --model models/onnx/safety_yolov8n.onnx --source storage/demo_videos/construction_safety.mp4 --api-url http://127.0.0.1:8000/api/v1
```

### 4. Запуск CV-воркера в режиме LinQ TPU
```bash
python run_worker.py --config configs/cv_engine.yaml --backend linq_tpu --model models/tpu/safety_yolov8_h1m.tpu --source rtsp://camera-stream/live --api-url http://127.0.0.1:8000/api/v1
```

### 5. Проверка тепловизора на лабораторном наборе данных
```powershell
.\.venv\Scripts\python.exe tools/replay_thermal_csv.py data/thermal/osf_sample/Beef_LR_38_20_30.csv --repeats 5 --interval 1
```

### 6. Запуск бенчмарка инференса
```powershell
# Замер производительности CPU/ONNX:
.\.venv\Scripts\python.exe bench.py --backend onnx --model models/onnx/safety_yolov8n.onnx --source storage/demo_videos/construction_safety.mp4 --warmup 10 --frames 100 --out bench_results.json

# Замер производительности LinQ TPU (на стенде):
python bench.py --backend linq --model models/tpu/torch_resnet50_b1_o5_h1m.tpu --warmup 10 --frames 100 --out bench_tpu.json
```
